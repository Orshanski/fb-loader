# FB Loader Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать функциональную спецификацию FB Loader (`docs/superpowers/specs/2026-05-01-fb-loader-design.md`): нативное macOS-приложение, открывающее INPX-индекс библиотеки Flibusta + папку zip-архивов, показывающее каталог по авторам/сериям, и выгружающее выбранные FB2 файлы.

**Architecture:** Swift / SwiftUI (macOS 26 Tahoe). Парсим INPX в in-memory структуры, кэшируем разобранную модель в свой бинарный файл с инвалидацией по SHA-256 содержимого INPX. Все запросы (поиск, фильтры, группировки) — in-memory. Метаданные FB2 для карточки книги читаются random-access из zip по требованию, обложки кэшируются в `~/Library/Caches/<bundle>/covers/`.

**Tech Stack:** Swift 6, SwiftUI, Swift Testing (для unit-тестов). Единственная сторонняя зависимость — **ZIPFoundation** (Swift Package Manager, github.com/weichsel/ZIPFoundation) для random-access по zip-архивам. SHA-256 — через CryptoKit.

**Source repo:** `/tmp/freelib/freeLib-mac/freeLib/src/` — оригинальный freeLib-mac (Qt/C++). Алгоритмы парсинга INPX, формата INP, выгрузки из zip переносятся отсюда; цитируются ниже в задачах.

## Conventions

- **TDD везде, где есть pure-логика** (модели, парсеры, кэш, экспорт-планировщик). Тесты пишутся первыми, должны провалиться, затем реализация. UI и I/O покрываются smoke-тестами или ручной проверкой.
- **Один шаг = одно действие**, 2–5 минут. Каждая задача завершается коммитом.
- **Тесты — Swift Testing**, не XCTest. `import Testing`, `@Test`, `#expect(...)`.
- **Идиоматика Swift 6:** `let` где можно, `Sendable` для типов, передаваемых между actor'ами.
- **Без unused кода:** удалить `Hello, World!` из `ContentView.swift` сразу.
- **Без Xcode auto-headers.** При первом редактировании любого файла, созданного Xcode'ом (`// FileName.swift / Project / Created by ... on .../...`), хедер удаляется. В новых файлах не пишется.
- **Коммиты атомарные**, сообщения в формате `feat: ...`, `test: ...`, `chore: ...`, `refactor: ...`. Без суффиксов `(Task N.M)` и без номеров задач — связь с планом видна по содержимому diff'а.
- **Запуск xcodebuild — только в шаге implementer'а** (один раз на task: либо `xcodebuild build`, либо `xcodebuild test -only-testing "FB LoaderTests"` для юнит-тестов; UI test target не запускать без явной необходимости — он стартует .app на экране пользователя). Spec-reviewer и code-quality reviewer работают по git diff и чтению файлов; xcodebuild у них вызывать запрещено.

```swift
import Foundation

struct Book: Identifiable, Hashable, Sendable {
    /// LIBID from INPX — the book's unique identifier inside the catalog.
    /// Also the filename inside the zip archive: "<libid>.fb2".
    let libid: Int32
    var id: Int32 { libid }

    let title: String
    let authorIDs: [Int32]      // first is primary
    let seriesID: Int32?
    let seriesNum: Int16?
    let genreIDs: [Int16]
    let language: String        // "ru", "en", or "" for unknown
    /// Index into `Library.archives` array (the zip filename without .zip extension).
    let archiveIndex: Int16
    /// Size in bytes (from INPX).
    let size: Int32
    /// Date added to the Flibusta library, not to the user's machine.
    /// Encoded as days since 2000-01-01 (4 bytes vs 8 of Date).
    let dateAddedDays: Int32
}

extension Book {
    static let dateEpoch: Date = {
        var c = DateComponents()
        c.year = 2000; c.month = 1; c.day = 1
        c.timeZone = TimeZone(identifier: "UTC")
        return Calendar(identifier: .gregorian).date(from: c)!
    }()

    var dateAdded: Date {
        Calendar(identifier: .gregorian).date(byAdding: .day, value: Int(dateAddedDays), to: Book.dateEpoch)!
    }
}
```

### Task 1.5: Library container

**Files:**
- Create: `FB Loader/FB Loader/Models/Library.swift`

- [ ] **Step 1: Реализация.** Это контейнер, без логики помимо построения вторичных индексов:

```swift
import Foundation

/// In-memory snapshot of the entire catalog. Built by `INPXImporter`,
/// persisted as a binary cache, queried by the UI.
/// All stored properties are `let`s of Sendable value types, so the
/// instance is safely shareable across actors after `init`.
final class Library: Sendable {
    let inpxHash: Data           // SHA-256 of INPX content
    let inpxVersion: String      // contents of version.info ("20260301" etc.)
    let archives: [String]       // .zip filenames (without extension), indexed by archiveIndex
    let authors: [Author]        // sorted by lastName, then firstName
    let series: [Series]         // sorted by name
    let genres: [Genre]
    let books: [Book]

    // Secondary indices (built once, after load):
    let authorByID: [Int32: Author]     // O(1) lookup, used by BookDetail and table rows
    let seriesByID: [Int32: Series]     // O(1) lookup
    let genreByID: [Int16: Genre]       // O(1) lookup
    let booksByAuthor: [Int32: [Int]]   // authorID → indices into `books`
    let booksBySeries: [Int32: [Int]]
    let bookCountByAuthor: [Int32: Int] // for the "(N)" counters
    let bookCountBySeries: [Int32: Int]
    let languages: [String]             // distinct languages found, sorted

    init(
        inpxHash: Data,
        inpxVersion: String,
        archives: [String],
        authors: [Author],
        series: [Series],
        genres: [Genre],
        books: [Book]
    ) {
        self.inpxHash = inpxHash
        self.inpxVersion = inpxVersion
        self.archives = archives
        self.authors = authors
        self.series = series
        self.genres = genres
        self.books = books

        // Build secondary indices.
        self.authorByID = Dictionary(uniqueKeysWithValues: authors.map { ($0.id, $0) })
        self.seriesByID = Dictionary(uniqueKeysWithValues: series.map { ($0.id, $0) })
        self.genreByID = Dictionary(uniqueKeysWithValues: genres.map { ($0.id, $0) })

        var byAuthor: [Int32: [Int]] = [:]
        var bySeries: [Int32: [Int]] = [:]
        var langSet = Set<String>()
        for (i, b) in books.enumerated() {
            for aid in b.authorIDs {
                byAuthor[aid, default: []].append(i)
            }
            if let sid = b.seriesID {
                bySeries[sid, default: []].append(i)
            }
            langSet.insert(b.language)
        }
        self.booksByAuthor = byAuthor
        self.booksBySeries = bySeries
        self.bookCountByAuthor = byAuthor.mapValues(\.count)
        self.bookCountBySeries = bySeries.mapValues(\.count)
        self.languages = Array(langSet).sorted()
    }
}
```

```swift
import Foundation

/// Loads and queries the FB2 genre dictionary embedded in the app bundle.
/// Source: extracted from freeLib.sqlite `genre` table.
///
/// **Concurrency:** not Sendable. `genre(forCode:)` mutates internal caches
/// (`syntheticByCode`, `nextSyntheticID`) when synthesizing entries for unknown
/// codes. Callers must access a single instance from one isolation domain.
/// In FB Loader, `INPXImporter` uses it during INPX parse and then discards it —
/// only the resolved `Genre` values flow into the `Sendable` `Library` snapshot.
final class GenreDictionary {
    private struct RawEntry: Decodable {
        let id: Int16
        let name: String
        let parentID: Int16
        let keys: String?

        // Explicit mapping so `parentID` (camelCase, matches Genre.parentID)
        // decodes from JSON key `"parent_id"` regardless of any global
        // `keyDecodingStrategy` the loader might add later.
        private enum CodingKeys: String, CodingKey {
            case id, name, keys
            case parentID = "parent_id"
        }
    }

    let allGenres: [Genre]
    private let byCode: [String: Genre]
    /// Synthetic genres created on demand for unknown FB2 codes.
    /// Negative IDs to avoid collision with real ones.
    private var syntheticByCode: [String: Genre] = [:]
    private var nextSyntheticID: Int16 = -1

    private init(rawEntries: [RawEntry]) {
        var all: [Genre] = []
        var byCode: [String: Genre] = [:]
        for r in rawEntries {
            let parent: Int16? = r.parentID == 0 ? nil : r.parentID
            // The "keys" column holds FB2 codes separated by ';' (matches freeLib
            // importthread.cpp:609). Names in freeLib.sqlite have trailing whitespace
            // (252/322 rows), so trim.
            let name = r.name.trimmingCharacters(in: .whitespacesAndNewlines)
            let keys = (r.keys ?? "")
                .split(separator: ";", omittingEmptySubsequences: true)
                .map(String.init)
            for code in keys {
                let g = Genre(id: r.id, code: code, name: name, parentID: parent)
                // Last entry wins on collisions. Source data has 4 codes that
                // appear twice (adv_animal, adv_geo, child_adv, drama_antique);
                // three are same-name duplicates from twin subtrees. `child_adv`
                // is the only true conflict — it always resolves to id=1012
                // ("Приключения для детей и подростков"). Matches freeLib's
                // QHash insertion semantics in importthread.cpp:613.
                byCode[code] = g
            }
            // Also keep one entry per `id` for navigation. Top-level categories
            // have empty `keys`, so `code` is "" — they're only reachable via parentID.
            all.append(Genre(id: r.id, code: keys.first ?? "", name: name, parentID: parent))
        }
        self.allGenres = all
        self.byCode = byCode
    }

    static func loadFromBundle(bundle: Bundle = .main) throws -> GenreDictionary {
        guard let url = bundle.url(forResource: "genres", withExtension: "json") else {
            throw NSError(domain: "GenreDictionary", code: 1,
                          userInfo: [NSLocalizedDescriptionKey: "genres.json not found in bundle"])
        }
        let data = try Data(contentsOf: url)
        let raw = try JSONDecoder().decode([RawEntry].self, from: data)
        return GenreDictionary(rawEntries: raw)
    }

    /// Returns a genre for the given FB2 code. For unknown non-empty codes,
    /// synthesizes a `Genre` whose `name` equals the code itself (per spec §7)
    /// and caches it so repeated lookups are stable. Returns `nil` for the
    /// empty string — there are no "" keys in the source dictionary, and a
    /// synthetic genre with empty code/name is never useful.
    func genre(forCode code: String) -> Genre? {
        guard !code.isEmpty else { return nil }
        if let g = byCode[code] { return g }
        if let g = syntheticByCode[code] { return g }
        let g = Genre(id: nextSyntheticID, code: code, name: code, parentID: nil)
        nextSyntheticID -= 1
        syntheticByCode[code] = g
        return g
    }
}
```

```swift
import Foundation

/// Mapping of logical INP fields to their column index in a record.
/// Defaults match freeLib's hard-coded fallback (importthread.cpp:685-722).
/// Real INPX archives override this via STRUCTURE.INFO.
///
/// Recognised tokens: AUTHOR, GENRE, TITLE, SERIES, SERNO, FILE, SIZE, LIBID,
/// DEL, EXT, DATE, LANG. Out of scope (not stored in `Book`): STARS, KEYWORDS,
/// FOLDER, TAG, TAGSERIES, TAGAUTHOR — silently ignored.
struct INPXFieldIndex: Sendable, Equatable {
    var author: Int
    var genre: Int
    var title: Int
    var series: Int
    var seriesNum: Int
    var file: Int
    var size: Int
    var libid: Int
    var deleted: Int
    var format: Int
    var date: Int
    var language: Int

    static let defaults = INPXFieldIndex(
        author: 0, genre: 1, title: 2, series: 3, seriesNum: 4,
        file: 5, size: 6, libid: 7, deleted: 8, format: 9, date: 10, language: 11
    )

    static func fromStructureInfo(_ text: String) -> INPXFieldIndex {
        // STRUCTURE.INFO may begin with a non-field header line (e.g.
        // "INPX VERSION;1.0") followed by the field row. freeLib iterates all
        // lines and accumulates positions (importthread.cpp:737-782). If no
        // recognised token is ever seen, fall back to defaults — that's a
        // header-only or malformed file, and silently returning all -1 would
        // drop the entire archive.
        var idx = INPXFieldIndex(
            author: -1, genre: -1, title: -1, series: -1, seriesNum: -1,
            file: -1, size: -1, libid: -1, deleted: -1, format: -1, date: -1, language: -1
        )
        var matched = false
        for line in text.split(whereSeparator: { $0 == "\n" || $0 == "\r" }) {
            let line = line.trimmingCharacters(in: .whitespaces)
            if line.isEmpty { continue }
            for (i, token) in line.uppercased().split(separator: ";").enumerated() {
                switch token {
                case "AUTHOR":   idx.author = i;     matched = true
                case "GENRE":    idx.genre = i;      matched = true
                case "TITLE":    idx.title = i;      matched = true
                case "SERIES":   idx.series = i;     matched = true
                case "SERNO":    idx.seriesNum = i;  matched = true
                case "FILE":     idx.file = i;       matched = true
                case "SIZE":     idx.size = i;       matched = true
                case "LIBID":    idx.libid = i;      matched = true
                case "DEL":      idx.deleted = i;    matched = true
                case "EXT":      idx.format = i;     matched = true
                case "DATE":     idx.date = i;       matched = true
                case "LANG":     idx.language = i;   matched = true
                default:         break
                }
            }
        }
        return matched ? idx : .defaults
    }
}
```

```swift
import Foundation

/// Parses INP `AUTHOR` field into structured triples.
/// Format: authors separated by `:`; each is `LastName,FirstName,MiddleName`.
/// All three components are optional (any may be empty).
enum INPAuthorParser {
    /// `Hashable` so `INPXImporter` can dedup authors via a dictionary keyed by triple.
    struct Triple: Hashable {
        let lastName: String
        let firstName: String
        let middleName: String
    }

    static func parse(_ field: String) -> [Triple] {
        guard !field.isEmpty else { return [] }
        return field.split(separator: ":", omittingEmptySubsequences: true).map { part in
            let comps = part.split(separator: ",", maxSplits: 2, omittingEmptySubsequences: false)
            func at(_ i: Int) -> String {
                i < comps.count ? String(comps[i]).trimmingCharacters(in: .whitespaces) : ""
            }
            return Triple(lastName: at(0), firstName: at(1), middleName: at(2))
        }
    }

    /// Detects records that mean "no known author".
    /// Matches the heuristics in importthread.cpp:951-953.
    static func isUnknown(lastName: String, firstName: String, middleName: String) -> Bool {
        let joined = (lastName + " " + firstName + " " + middleName).lowercased()
        if joined.contains("автор") &&
           (joined.contains("неизвестен") || joined.contains("неизвестный")) {
            return true
        }
        if joined.trimmingCharacters(in: .whitespaces) == "неизвестно" { return true }
        return false
    }
}
```

```swift
import Foundation

/// Structured representation of one INP record (one book).
/// Field references match the order in `INPXFieldIndex`.
struct INPRecord {
    let authorField: String
    let genreField: String
    let title: String
    let seriesName: String
    let seriesNum: Int16?
    let fileBaseName: String      // libid as string, used as filename inside zip
    let size: Int32
    let libid: Int32
    let deleted: Bool
    let format: String
    let dateAdded: Date?
    let language: String
}

enum INPRecordParser {
    static func parse(line: String, fieldIndex: INPXFieldIndex) -> INPRecord? {
        if line.isEmpty { return nil }
        let parts = line.split(separator: "\u{04}", omittingEmptySubsequences: false)
        func at(_ i: Int) -> String {
            i >= 0 && i < parts.count
                ? String(parts[i]).trimmingCharacters(in: .whitespaces)
                : ""
        }
        let author = at(fieldIndex.author)
        let genre = at(fieldIndex.genre)
        let title = at(fieldIndex.title)
        let seriesName = at(fieldIndex.series)
        let seriesNumStr = at(fieldIndex.seriesNum)
        let file = at(fieldIndex.file)
        let sizeStr = at(fieldIndex.size)
        let libidStr = at(fieldIndex.libid)
        let delStr = at(fieldIndex.deleted)
        let format = at(fieldIndex.format)
        let dateStr = at(fieldIndex.date)
        var language = at(fieldIndex.language)
        if language.count > 2 {
            language = String(language.prefix(2))
        }

        return INPRecord(
            authorField: author,
            genreField: genre,
            title: title,
            seriesName: seriesName,
            seriesNum: Int16(seriesNumStr),
            fileBaseName: file,
            size: Int32(sizeStr) ?? 0,
            libid: Int32(libidStr) ?? 0,
            deleted: (Int(delStr) ?? 0) > 0,
            format: format,
            dateAdded: parseDate(dateStr),
            language: language
        )
    }

    private static func parseDate(_ s: String) -> Date? {
        guard s.count == 10 else { return nil }
        let comps = s.split(separator: "-")
        guard comps.count == 3,
              let y = Int(comps[0]), let m = Int(comps[1]), let d = Int(comps[2]) else {
            return nil
        }
        var dc = DateComponents()
        dc.year = y; dc.month = m; dc.day = d
        dc.timeZone = TimeZone(identifier: "UTC")
        return Calendar(identifier: .gregorian).date(from: dc)
    }
}
```

```swift
import Foundation
import ZIPFoundation

/// Imports an INPX archive into an in-memory `Library`.
/// Skips records with DEL=1.
/// Author dedup is by (lastName, firstName, middleName) tuple.
/// Empty/unknown authors are mapped to the synthetic `Author.unknown`.
enum INPXImporter {
    enum ImportError: Error {
        /// Wraps the actual ZIPFoundation error for diagnostics — never silently lost.
        case cannotOpenArchive(URL, underlying: Error)
        case noVersionInfo
        case tooManyArchives(count: Int)
    }

    /// Cached `CharacterSet` for the line-trim step. Built once and reused across 700k iterations.
    private static let trimSet: CharacterSet = .controlCharacters
        .subtracting(.init(charactersIn: "\u{04}"))

    static func import_(inpxURL: URL, genres: GenreDictionary) throws -> Library {
        let inpxData = try Data(contentsOf: inpxURL)
        let inpxHash = SHA256.hash(of: inpxData)

        let archive: Archive
        do {
            archive = try Archive(data: inpxData, accessMode: .read)
        } catch {
            throw ImportError.cannotOpenArchive(inpxURL, underlying: error)
        }

        // 1. version.info — case-insensitive lookup (some INPX dumps use VERSION.INFO).
        var version = ""
        if let entry = archive.first(where: { $0.path.lowercased() == "version.info" }) {
            var data = Data()
            _ = try archive.extract(entry) { data.append($0) }
            version = String(decoding: data, as: UTF8.self)
                .trimmingCharacters(in: .whitespacesAndNewlines)
        } else {
            throw ImportError.noVersionInfo
        }

        // 2. STRUCTURE.INFO (optional) — case-insensitive.
        var fieldIndex = INPXFieldIndex.defaults
        if let entry = archive.first(where: { $0.path.lowercased() == "structure.info" }) {
            var data = Data()
            _ = try archive.extract(entry) { data.append($0) }
            fieldIndex = INPXFieldIndex.fromStructureInfo(
                String(decoding: data, as: UTF8.self))
        }

        // 3. Iterate .inp files, build catalog.
        var archiveNames: [String] = []
        var archiveIndexByName: [String: Int16] = [:]
        var authorIDs: [INPAuthorParser.Triple: Int32] = [:]
        var authors: [Author] = []
        var seriesIDs: [String: Int32] = [:]
        var series: [Series] = []
        var books: [Book] = []

        let unknownAuthor = Author.unknown
        // Reserve slot 0 for unknown.
        authors.append(unknownAuthor)
        authorIDs[INPAuthorParser.Triple(lastName: "", firstName: "", middleName: "")]
            = unknownAuthor.id

        for entry in archive {
            let name = entry.path
            guard name.lowercased().hasSuffix(".inp") else { continue }

            // archiveIndex maps to the corresponding .zip filename without extension —
            // exactly as freeLib does (importthread.cpp:250 replaces ".inp" with ".zip").
            let archBase = (name as NSString).deletingPathExtension
            let archIdx: Int16
            if let i = archiveIndexByName[archBase] {
                archIdx = i
            } else {
                let nextIdx = archiveNames.count
                if nextIdx >= Int(Int16.max) {
                    throw ImportError.tooManyArchives(count: nextIdx)
                }
                archIdx = Int16(nextIdx)
                archiveIndexByName[archBase] = archIdx
                archiveNames.append(archBase)
            }

            var inpData = Data()
            _ = try archive.extract(entry) { inpData.append($0) }
            let text = String(decoding: inpData, as: UTF8.self)

            for line in text.split(separator: "\n", omittingEmptySubsequences: true) {
                let trimmed = String(line).trimmingCharacters(in: trimSet)
                guard let rec = INPRecordParser.parse(line: trimmed, fieldIndex: fieldIndex)
                else { continue }
                if rec.deleted { continue }

                // Genres
                let genreCodes = rec.genreField.split(separator: ":",
                                                      omittingEmptySubsequences: true)
                let genreIDs: [Int16] = genreCodes.compactMap { code in
                    genres.genre(forCode: String(code).trimmingCharacters(in: .whitespaces))?.id
                }

                // Authors
                let triples = INPAuthorParser.parse(rec.authorField)
                    .filter { !($0.lastName.isEmpty && $0.firstName.isEmpty && $0.middleName.isEmpty) }
                var bookAuthorIDs: [Int32] = []
                for t in triples {
                    if INPAuthorParser.isUnknown(
                        lastName: t.lastName, firstName: t.firstName, middleName: t.middleName) {
                        continue
                    }
                    if let existing = authorIDs[t] {
                        bookAuthorIDs.append(existing)
                    } else {
                        let newID = Int32(authors.count)
                        let a = Author(id: newID,
                                       lastName: t.lastName,
                                       firstName: t.firstName,
                                       middleName: t.middleName)
                        authors.append(a)
                        authorIDs[t] = newID
                        bookAuthorIDs.append(newID)
                    }
                }
                if bookAuthorIDs.isEmpty {
                    bookAuthorIDs = [Author.unknownID]
                }

                // Series
                var seriesID: Int32? = nil
                if !rec.seriesName.isEmpty {
                    if let existing = seriesIDs[rec.seriesName] {
                        seriesID = existing
                    } else {
                        let newID = Int32(series.count + 1) // 0 reserved for "no series"
                        series.append(Series(id: newID, name: rec.seriesName))
                        seriesIDs[rec.seriesName] = newID
                        seriesID = newID
                    }
                }

                // Date → days since Book.dateEpoch
                let days: Int32
                if let d = rec.dateAdded {
                    let interval = Int(d.timeIntervalSince(Book.dateEpoch) / 86400)
                    days = Int32(interval)
                } else {
                    days = 0
                }

                books.append(Book(
                    libid: rec.libid,
                    title: rec.title,
                    authorIDs: bookAuthorIDs,
                    seriesID: seriesID,
                    seriesNum: rec.seriesNum,
                    genreIDs: genreIDs,
                    language: rec.language,
                    archiveIndex: archIdx,
                    size: rec.size,
                    dateAddedDays: days
                ))
            }
        }

        // Sort authors by lastName, firstName, middleName.
        // The synthetic "(Без автора)" placeholder is included only when at least
        // one book actually references it — clean libraries don't show an empty
        // placeholder. When present, it always goes to the end of the list,
        // following the standard "Other" UX pattern.
        let unknownReferenced = books.contains { $0.authorIDs.contains(Author.unknownID) }
        let visibleAuthors = unknownReferenced
            ? authors
            : authors.filter { $0.id != Author.unknownID }
        let sortedAuthors = visibleAuthors.sorted { a, b in
            if a.id == Author.unknownID { return false }
            if b.id == Author.unknownID { return true }
            return (a.lastName, a.firstName, a.middleName)
                 < (b.lastName, b.firstName, b.middleName)
        }
        let sortedSeries = series.sorted { $0.name.localizedCaseInsensitiveCompare($1.name) == .orderedAscending }

        return Library(
            inpxHash: inpxHash,
            inpxVersion: version,
            archives: archiveNames,
            authors: sortedAuthors,
            series: sortedSeries,
            genres: genres.allGenres,
            books: books
        )
    }
}
```

```swift
import Foundation

/// Binary on-disk format:
///   "FBLC"   4B    magic
///   version  uint16 (current = 1)
///   inpxHash 32B
///   inpxVersionLen uint16, inpxVersion utf8 bytes
///   archivesCount uint32, then for each: len(uint16) + utf8 bytes
///   authorsCount uint32, then for each:
///       id int32; lastName, firstName, middleName (len uint16 + utf8)
///   seriesCount uint32, then for each: id int32; name (len uint16 + utf8)
///   genresCount uint32, then for each: id int16; code; name; parentID int32 (-1 = nil)
///   booksCount uint32, then for each:
///       libid int32; title len+utf8;
///       authorIDs count(uint16) + ints32
///       seriesID int32 (-1=nil); seriesNum int16 (Int16.min=nil)
///       genreIDs count(uint16) + ints16
///       language len(uint8) + utf8
///       archiveIndex int16
///       size int32
///       dateAddedDays int32
enum LibraryBinaryCodec {
    enum DecodeError: Error {
        case badMagic
        case unsupportedVersion(UInt16)
        case truncated
    }
    enum EncodeError: Error {
        /// Signalled instead of `precondition` to avoid crashing the whole process
        /// if a single book's title (or other length-prefixed string) exceeds
        /// the on-disk format's length encoding capacity.
        case stringTooLong(field: String, length: Int, max: Int)
    }

    private static let magic: [UInt8] = Array("FBLC".utf8)
    private static let formatVersion: UInt16 = 1

    static func encode(_ lib: Library) throws -> Data {
        var w = BinaryWriter()
        w.bytes(magic)
        w.uint16(formatVersion)
        w.bytes(Array(lib.inpxHash))
        try w.string16(lib.inpxVersion, field: "inpxVersion")
        w.uint32(UInt32(lib.archives.count))
        for s in lib.archives { try w.string16(s, field: "archive") }
        w.uint32(UInt32(lib.authors.count))
        for a in lib.authors {
            w.int32(a.id)
            try w.string16(a.lastName, field: "author.lastName")
            try w.string16(a.firstName, field: "author.firstName")
            try w.string16(a.middleName, field: "author.middleName")
        }
        w.uint32(UInt32(lib.series.count))
        for s in lib.series {
            w.int32(s.id); try w.string16(s.name, field: "series.name")
        }
        w.uint32(UInt32(lib.genres.count))
        for g in lib.genres {
            w.int16(g.id)
            try w.string16(g.code, field: "genre.code")
            try w.string16(g.name, field: "genre.name")
            w.int32(g.parentID.map(Int32.init) ?? -1)
        }
        w.uint32(UInt32(lib.books.count))
        for b in lib.books {
            w.int32(b.libid)
            try w.string16(b.title, field: "book.title")
            w.uint16(UInt16(b.authorIDs.count))
            for id in b.authorIDs { w.int32(id) }
            w.int32(b.seriesID ?? -1)
            w.int16(b.seriesNum ?? Int16.min)
            w.uint16(UInt16(b.genreIDs.count))
            for g in b.genreIDs { w.int16(g) }
            try w.string8(b.language, field: "book.language")
            w.int16(b.archiveIndex)
            w.int32(b.size)
            w.int32(b.dateAddedDays)
        }
        return w.data
    }

    static func decode(_ data: Data) throws -> Library {
        var r = BinaryReader(data: data)
        guard try r.bytes(4) == magic else { throw DecodeError.badMagic }
        let v = try r.uint16()
        guard v == formatVersion else { throw DecodeError.unsupportedVersion(v) }
        let inpxHash = Data(try r.bytes(32))
        let inpxVersion = try r.string16()
        let archCount = try r.uint32()
        var archives: [String] = []
        archives.reserveCapacity(Int(archCount))
        for _ in 0..<archCount { archives.append(try r.string16()) }
        let authCount = try r.uint32()
        var authors: [Author] = []
        authors.reserveCapacity(Int(authCount))
        for _ in 0..<authCount {
            let id = try r.int32()
            let ln = try r.string16(); let fn = try r.string16(); let mn = try r.string16()
            authors.append(Author(id: id, lastName: ln, firstName: fn, middleName: mn))
        }
        let serCount = try r.uint32()
        var series: [Series] = []
        series.reserveCapacity(Int(serCount))
        for _ in 0..<serCount {
            series.append(Series(id: try r.int32(), name: try r.string16()))
        }
        let genCount = try r.uint32()
        var genres: [Genre] = []
        genres.reserveCapacity(Int(genCount))
        for _ in 0..<genCount {
            let id = try r.int16(); let code = try r.string16(); let name = try r.string16()
            let p = try r.int32()
            genres.append(Genre(id: id, code: code, name: name,
                                parentID: p == -1 ? nil : Int16(p)))
        }
        let bookCount = try r.uint32()
        var books: [Book] = []
        books.reserveCapacity(Int(bookCount))
        for _ in 0..<bookCount {
            let libid = try r.int32()
            let title = try r.string16()
            let aCount = try r.uint16()
            var aIDs: [Int32] = []; aIDs.reserveCapacity(Int(aCount))
            for _ in 0..<aCount { aIDs.append(try r.int32()) }
            let s = try r.int32()
            let sn = try r.int16()
            let gCount = try r.uint16()
            var gIDs: [Int16] = []; gIDs.reserveCapacity(Int(gCount))
            for _ in 0..<gCount { gIDs.append(try r.int16()) }
            let lang = try r.string8()
            let archIdx = try r.int16()
            let size = try r.int32()
            let days = try r.int32()
            books.append(Book(
                libid: libid, title: title, authorIDs: aIDs,
                seriesID: s == -1 ? nil : s,
                seriesNum: sn == Int16.min ? nil : sn,
                genreIDs: gIDs, language: lang, archiveIndex: archIdx,
                size: size, dateAddedDays: days
            ))
        }
        return Library(
            inpxHash: inpxHash,
            inpxVersion: inpxVersion,
            archives: archives,
            authors: authors,
            series: series,
            genres: genres,
            books: books
        )
    }
}

private struct BinaryWriter {
    var data = Data()
    mutating func bytes(_ b: [UInt8]) { data.append(contentsOf: b) }
    mutating func uint16(_ v: UInt16) { var v = v.littleEndian; withUnsafeBytes(of: &v) { data.append(contentsOf: $0) } }
    mutating func uint32(_ v: UInt32) { var v = v.littleEndian; withUnsafeBytes(of: &v) { data.append(contentsOf: $0) } }
    mutating func int16(_ v: Int16)   { var v = v.littleEndian; withUnsafeBytes(of: &v) { data.append(contentsOf: $0) } }
    mutating func int32(_ v: Int32)   { var v = v.littleEndian; withUnsafeBytes(of: &v) { data.append(contentsOf: $0) } }
    mutating func string16(_ s: String, field: String) throws {
        let utf = Array(s.utf8)
        guard utf.count <= Int(UInt16.max) else {
            throw LibraryBinaryCodec.EncodeError.stringTooLong(
                field: field, length: utf.count, max: Int(UInt16.max))
        }
        uint16(UInt16(utf.count))
        bytes(utf)
    }
    mutating func string8(_ s: String, field: String) throws {
        let utf = Array(s.utf8)
        guard utf.count <= Int(UInt8.max) else {
            throw LibraryBinaryCodec.EncodeError.stringTooLong(
                field: field, length: utf.count, max: Int(UInt8.max))
        }
        var len = UInt8(utf.count); withUnsafeBytes(of: &len) { data.append(contentsOf: $0) }
        bytes(utf)
    }
}

private struct BinaryReader {
    let data: Data
    var offset: Int = 0
    init(data: Data) { self.data = data }
    mutating func bytes(_ n: Int) throws -> [UInt8] {
        guard offset + n <= data.count else { throw LibraryBinaryCodec.DecodeError.truncated }
        defer { offset += n }
        return Array(data[offset..<offset+n])
    }
    mutating func uint8() throws -> UInt8 { (try bytes(1))[0] }
    mutating func uint16() throws -> UInt16 {
        let b = try bytes(2)
        return UInt16(b[0]) | (UInt16(b[1]) << 8)
    }
    mutating func uint32() throws -> UInt32 {
        let b = try bytes(4)
        return UInt32(b[0]) | (UInt32(b[1]) << 8) | (UInt32(b[2]) << 16) | (UInt32(b[3]) << 24)
    }
    mutating func int16() throws -> Int16 { Int16(bitPattern: try uint16()) }
    mutating func int32() throws -> Int32 { Int32(bitPattern: try uint32()) }
    mutating func string16() throws -> String {
        let n = try uint16()
        let b = try bytes(Int(n))
        return String(decoding: b, as: UTF8.self)
    }
    mutating func string8() throws -> String {
        let n = try uint8()
        let b = try bytes(Int(n))
        return String(decoding: b, as: UTF8.self)
    }
```

```swift
import Foundation

/// Caches the parsed Library on disk and decides whether to reparse.
/// Cache is invalidated when the SHA-256 of the INPX content changes
/// (path is not a factor — same INPX moved elsewhere does not invalidate).
final class LibraryCacheStore {
    private let cacheURL: URL

    init(applicationSupportRoot: URL) {
        try? FileManager.default.createDirectory(
            at: applicationSupportRoot,
            withIntermediateDirectories: true)
        self.cacheURL = applicationSupportRoot.appendingPathComponent("library-cache.bin")
    }

    func loadOrRebuild(
        inpxURL: URL,
        genres: GenreDictionary,
        rebuild: () throws -> Library
    ) throws -> Library {
        let currentHash = try SHA256.hash(ofFileAt: inpxURL)

        if let cached = try? Data(contentsOf: cacheURL),
           let lib = try? LibraryBinaryCodec.decode(cached),
           lib.inpxHash == currentHash {
            return lib
        }

        let fresh = try rebuild()
        try save(fresh)
        return fresh
    }

    private func save(_ lib: Library) throws {
        let data = try LibraryBinaryCodec.encode(lib)
        let tmp = cacheURL.appendingPathExtension("tmp")
        try data.write(to: tmp, options: [.atomic])
        if FileManager.default.fileExists(atPath: cacheURL.path) {
            try FileManager.default.removeItem(at: cacheURL)
        }
        try FileManager.default.moveItem(at: tmp, to: cacheURL)
    }
}
```

```swift
struct FB2BookInfo {
    let bookTitle: String?
    let annotation: String?
    let dateWritten: String?
    let translators: [INPAuthorParser.Triple]
    let coverImageData: Data?

/// Parses the `<description>` block of an FB2 file plus the `<binary>` element
/// referenced by `<coverpage><image l:href="#..."/>`.
/// Reads only the prefix needed to find description+cover; the caller can pass
/// just the first ~64 KB of the file.
enum FB2DescriptionParser {
    enum ParseError: Error { case malformed }

    static func parse(data: Data) throws -> FB2BookInfo {
        let delegate = FB2Delegate()
        let parser = XMLParser(data: data)
        parser.delegate = delegate
        parser.shouldProcessNamespaces = true
        parser.parse()
        // Resolve cover binary by id.
        var cover: Data? = nil
        if let href = delegate.coverHref?.trimmingCharacters(in: .init(charactersIn: "#")),
           let b64 = delegate.binariesByID[href] {
            cover = Data(base64Encoded: b64.replacingOccurrences(of: "\n", with: "")
                                          .replacingOccurrences(of: "\r", with: "")
                                          .trimmingCharacters(in: .whitespaces))
        }
        return FB2BookInfo(
            bookTitle: delegate.bookTitle,
            annotation: delegate.annotation,
            dateWritten: delegate.dateWritten,
            translators: delegate.translators,
            coverImageData: cover
        )
    }
}

private final class FB2Delegate: NSObject, XMLParserDelegate {
    // State machine
    private enum Section { case none, titleInfo, author, translator, annotation, coverpage, binary }
    private var section: Section = .none
    private var inDescription = false
    private var currentBinaryID: String?
    private var currentBinaryBuffer = ""
    private var currentTextField: String = "" // accumulator for text() inside small fields

    var bookTitle: String?
    var annotation: String?
    var dateWritten: String?
    var translators: [INPAuthorParser.Triple] = []
    var coverHref: String?
    var binariesByID: [String: String] = [:]

    private var translatorBuilder: (last: String, first: String, middle: String) = ("", "", "")
    private var authorElementStack: [String] = []   // for author/translator subfields
    private var annotationBuffer = ""
    private var inAnnotationDepth = 0

    func parser(_ parser: XMLParser,
                didStartElement elementName: String,
                namespaceURI: String?,
                qualifiedName qName: String?,
                attributes attributeDict: [String : String] = [:]) {
        let n = elementName.lowercased()
        if n == "description" { inDescription = true }
        guard inDescription else {
            if n == "binary" {
                section = .binary
                currentBinaryID = attributeDict["id"]
                currentBinaryBuffer = ""
            }
            return
        }
        switch n {
        case "title-info": section = .titleInfo
        case "author" where section == .titleInfo: section = .author
        case "translator" where section == .titleInfo:
            section = .translator
            translatorBuilder = ("", "", "")
        case "annotation" where section == .titleInfo:
            section = .annotation
            annotationBuffer = ""
            inAnnotationDepth = 1
        case "coverpage" where section == .titleInfo: section = .coverpage
        case "image" where section == .coverpage:
            if let href = attributeDict["href"] ?? attributeDict["l:href"] {
                coverHref = href
            }
        case "first-name", "last-name", "middle-name", "book-title", "date":
            currentTextField = ""
            authorElementStack.append(n)
        default:
            if section == .annotation { inAnnotationDepth += 1 }
        }
    }

    func parser(_ parser: XMLParser, foundCharacters string: String) {
        if section == .binary { currentBinaryBuffer += string; return }
        if section == .annotation { annotationBuffer += string; return }
        if !authorElementStack.isEmpty { currentTextField += string }
    }

    func parser(_ parser: XMLParser,
                didEndElement elementName: String,
                namespaceURI: String?,
                qualifiedName qName: String?) {
        let n = elementName.lowercased()
        switch n {
        case "binary":
            if let id = currentBinaryID { binariesByID[id] = currentBinaryBuffer }
            section = .none
        case "first-name", "last-name", "middle-name", "book-title", "date":
            let value = currentTextField.trimmingCharacters(in: .whitespacesAndNewlines)
            authorElementStack.removeLast()
            switch (section, n) {
            case (.titleInfo, "book-title"): bookTitle = value
            case (.titleInfo, "date"): dateWritten = value
            case (.translator, "first-name"): translatorBuilder.first = value
            case (.translator, "last-name"): translatorBuilder.last = value
            case (.translator, "middle-name"): translatorBuilder.middle = value
            default: break
            }
        case "translator":
            translators.append(.init(
                lastName: translatorBuilder.last,
                firstName: translatorBuilder.first,
                middleName: translatorBuilder.middle))
            section = .titleInfo
        case "author" where section == .author: section = .titleInfo
        case "coverpage" where section == .coverpage: section = .titleInfo
        case "annotation":
            inAnnotationDepth -= 1
            if inAnnotationDepth <= 0 {
                annotation = annotationBuffer.trimmingCharacters(in: .whitespacesAndNewlines)
                section = .titleInfo
            }
        case "title-info" where section == .titleInfo: section = .none
        case "description": inDescription = false
        default:
            if section == .annotation { inAnnotationDepth -= 1 }
        }
    }
}
```

```swift
import Foundation

/// Opens a zip archive and extracts a single FB2 file into memory.
/// Uses ZIPFoundation, which performs random access via the central directory.
final class ZipFB2Reader {
    enum ReaderError: Error {
        case archiveNotFound(URL)
        /// Wraps the actual ZIPFoundation error so the cause is visible in logs.
        case archiveCorrupt(URL, underlying: Error)
        case bookNotFoundInArchive(zip: URL, libid: Int32)
    }

    /// Reads the bytes of `<libid>.fb2` from the given zip.
    static func readFB2(libid: Int32, archiveURL: URL) throws -> Data {
        guard FileManager.default.fileExists(atPath: archiveURL.path) else {
            throw ReaderError.archiveNotFound(archiveURL)
        }
        let archive: Archive
        do {
            archive = try Archive(url: archiveURL, accessMode: .read)
        } catch {
            throw ReaderError.archiveCorrupt(archiveURL, underlying: error)
        }
        let name = "\(libid).fb2"
        guard let entry = archive[name] else {
            throw ReaderError.bookNotFoundInArchive(zip: archiveURL, libid: libid)
        }
        var data = Data()
        _ = try archive.extract(entry) { data.append($0) }
        return data
    }
}
```

```swift
enum LibraryLoader {
```

```swift
import Foundation

enum BooksByContext {
    enum Context { case author(Int32), series(Int32) }
    /// Sentinel token used in the language filter to mean "language not set in INPX".
    static let unspecifiedLanguageToken = "__none__"

    static func books(for ctx: Context, language: String, in lib: Library) -> [Book] {
        let indices: [Int]
        switch ctx {
        case .author(let id): indices = lib.booksByAuthor[id] ?? []
        case .series(let id): indices = lib.booksBySeries[id] ?? []
        }
        let langKey: String
        if language == unspecifiedLanguageToken { langKey = "" }
        else { langKey = language }
        return indices.compactMap { i in
            let b = lib.books[i]
            return b.language == langKey ? b : nil
        }
    }
}
```

```swift
import Foundation
import AppKit

/// Lazy-fills `~/Library/Caches/<bundleID>/covers/<libid>.jpg`.
/// On a miss, opens the book's zip via ZipFB2Reader, parses the FB2 prefix,
/// extracts cover bytes, writes to disk.
///
/// `@unchecked Sendable` is sound here: the only state is the immutable
/// `cacheDir` URL; concurrent writes to disk go through atomic FileManager
/// operations (`Data.write(options: .atomic)`), and concurrent reads of an
/// already-cached file are safe at the OS level.
final class CoverCache: @unchecked Sendable {
    private let cacheDir: URL

    init() throws {
        let fm = FileManager.default
        let base = try fm.url(for: .cachesDirectory, in: .userDomainMask,
                              appropriateFor: nil, create: true)
        let dir = base.appendingPathComponent(Bundle.main.bundleIdentifier ?? "FB-Loader",
                                              isDirectory: true)
            .appendingPathComponent("covers", isDirectory: true)
        try fm.createDirectory(at: dir, withIntermediateDirectories: true)
        self.cacheDir = dir
    }

    func image(for book: Book, in library: Library, archivesRoot: URL) -> NSImage? {
        let cached = cacheDir.appendingPathComponent("\(book.libid).jpg")
        if let img = NSImage(contentsOf: cached) { return img }
        // Parse FB2 to extract cover
        let archiveName = library.archives[Int(book.archiveIndex)] + ".zip"
        let archiveURL = archivesRoot.appendingPathComponent(archiveName)
        guard let fb2 = try? ZipFB2Reader.readFB2(libid: book.libid, archiveURL: archiveURL),
              let info = try? FB2DescriptionParser.parse(data: fb2.prefix(64 * 1024)),
              let cover = info.coverImageData else {
            return nil
        }
        try? cover.write(to: cached, options: .atomic)
        return NSImage(data: cover)
    }
}
```

```swift
enum ExportPlanner {
    /// Forbidden in HFS+/APFS filenames or commonly problematic across tools.
    private static let forbidden: Set<Character> = [":", "/", "\\", "?", "*", "<", ">", "|", "\""]
    /// macOS filename limit (NAME_MAX) is 255; we cap a bit lower for safety.
    private static let nameMax = 220

    static func plan(libids: Set<Int32>,
                     rootFolder: URL,
                     selectedAuthorID: Int32?,
                     selectedSeriesID: Int32?,
                     in library: Library) -> [ExportItem] {
        let booksByLibid = Dictionary(uniqueKeysWithValues: library.books.map { ($0.libid, $0) })
        let authorsByID = Dictionary(uniqueKeysWithValues: library.authors.map { ($0.id, $0) })
        return libids.compactMap { id in booksByLibid[id] }.map { book in
            let folderName = folderName(for: book,
                                        selectedAuthorID: selectedAuthorID,
                                        selectedSeriesID: selectedSeriesID,
                                        authorsByID: authorsByID)
            let folder = rootFolder.appendingPathComponent(sanitized(folderName), isDirectory: true)
            let dest = folder.appendingPathComponent(sanitized(book.title) + ".fb2")
            return ExportItem(book: book, archiveURL: nil, destination: dest)
        }
    }

    private static func folderName(for book: Book,
                                   selectedAuthorID: Int32?,
                                   selectedSeriesID: Int32?,
                                   authorsByID: [Int32: Author]) -> String {
        // 1. If user has selected an author in the sidebar — use that author's name,
        //    even if they are not the first author of the book.
        if let aid = selectedAuthorID, let a = authorsByID[aid] {
            return a.displayName
        }
        // 2. Else use the first author of the book.
        if let firstID = book.authorIDs.first, let a = authorsByID[firstID] {
            return a.displayName
        }
        return Author.unknown.displayName
    }

    static func sanitized(_ name: String) -> String {
        var s = String(name.map { forbidden.contains($0) ? "_" : $0 })
        if s.utf8.count > nameMax {
            s = String(s.prefix(nameMax))
        }
        return s.trimmingCharacters(in: .whitespaces)
    }
}
```

```swift
import Foundation

enum ExportRunner {
    /// Runs entirely on the main actor so `progress` can be mutated without hops.
    /// Heavy I/O (zip read + file write) is dispatched off-main via `Task.detached`.
    /// One detached task per book — sequential to keep disk/network thrashing low and
    /// to match freeLib's behaviour (exportthread.cpp processes books one by one).
    @MainActor
    static func run(items: [ExportItem],
                    archivesRoot: URL,
                    library: Library,
                    progress: ExportProgress) async {
        progress.total = items.count
        progress.done = 0
        progress.currentTitle = ""
        progress.cancelled = false
        progress.failed = []

        for item in items {
            if progress.cancelled { return }
            progress.currentTitle = item.book.title

            let book = item.book
            let dest = item.destination
            let archives = archivesRoot
            let archiveName = library.archives[Int(book.archiveIndex)] + ".zip"

            // Off-main: open zip, extract bytes, write to disk.
            // Returns nil on success, or the error message on failure.
            let errorMessage: String? = await Task.detached(priority: .utility) { () -> String? in
                let archiveURL = archives.appendingPathComponent(archiveName)
                do {
                    let data = try ZipFB2Reader.readFB2(libid: book.libid, archiveURL: archiveURL)
                    try FileManager.default.createDirectory(
                        at: dest.deletingLastPathComponent(),
                        withIntermediateDirectories: true)
                    try data.write(to: dest, options: .atomic)
                    return nil
                } catch {
                    return "\(error)"
                }
            }.value

            if let msg = errorMessage {
                progress.failed.append((book.title, msg))
            }
            progress.done += 1
        }
    }
}
```
