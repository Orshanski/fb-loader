# Кнопка «Найти» в фильтре по дате — только после правки

## Задача

В поповере фильтра по дате (`UI/BooksTable/DateFilterPopover.swift`)
кнопка «Найти» активна, только если хотя бы одна граница отличается от
той, что стояла в поле при открытии поповера.

Дополняет [спеку фильтра по дате](2026-08-07-books-date-filter-design.md).

## Правило

- Исходное состояние — значения полей «с» и «по» в момент открытия
  поповера. Фиксируется один раз при открытии и до закрытия не меняется.
- Сравнение по дню: обе стороны приводятся к полуночи
  (`Calendar.startOfDay`) одним календарём. Время внутри дня правкой не
  считается.
- Сравниваются значения, а не факт правки: поменять дату и вернуть
  прежнюю — кнопка снова неактивна.
- Неактивная «Найти» не срабатывает и по Enter.
- «Сбросить» не меняется: активна всегда.

## Модель

`Models/DateFilterDraft.swift`:

```swift
nonisolated struct DateFilterDraft: Equatable, Sendable {
    let initial: DateRangeFilter   // поля при открытии, приведённые к полуночи
    var from: Date
    var to: Date

    init(from: Date, to: Date, calendar: Calendar = .current)
    var applied: DateRangeFilter   // текущие поля, приведённые к полуночи
    var canApply: Bool             // applied != initial
}
```

`DateFilterPopover`:

- `@State private var draft: DateFilterDraft` вместо `@State from/to`;
  создаётся в `init` из тех же значений, что раньше шли в поля. `@State`
  держит первое значение при повторных вызовах `init` во время
  перерисовки родителя, поэтому `initial` не дрейфует.
- Поля и календарь работают через `$draft.from` / `$draft.to`.
- «Найти»: `onApply(draft.applied)`,
  `.keyboardShortcut(.defaultAction).disabled(!draft.canApply)`.
- Приватный `applied()` удаляется — его работа в `DateFilterDraft`.
- Doc-комментарий типа дополняется правилом активности «Найти».

## Правка родительской спеки

Фраза «"Найти" с нетронутыми полями ничего не отсекает» заменяется на
«С нетронутыми полями "Найти" неактивна (см. 2026-10-15)».

## Тесты

`DateFilterDraftTests.swift`, календарь с фиксированным часовым поясом:

- поля не тронуты → `canApply == false`;
- исходное «по» с часами, поле «по» — полночь того же дня → `false`;
- поле «по» — тот же день с другим временем → `false`;
- изменено «с» → `true`;
- изменено «по» → `true`;
- изменено и возвращено → `false`;
- `applied` приводит обе границы к полуночи.

## Ручное UI-тестирование

- Открыть поповер — «Найти» неактивна, Enter ничего не делает.
- Поменять «с» или «по» — «Найти» активна; применить — фильтр работает.
- Поменять дату и вернуть прежнюю — «Найти» снова неактивна.
- Выбрать в сетке тот же день или нажать «Сегодня», когда в поле уже
  сегодня, — «Найти» неактивна.
- С активным фильтром: открыть — неактивна; поменять границу — активна.
- Поменять дату, закрыть по Esc, открыть снова — «Найти» неактивна.
- «Сбросить» активна во всех случаях.
