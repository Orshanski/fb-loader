# Таблица книг на NSTableView

## Задача

Таблица книг главного окна (`UI/BooksTable/BooksTableView.swift`,
`BookRow.swift`) нарисована вручную: `ScrollView` + `LazyVStack` +
`onTapGesture`. Нет стрелок, фокуса, Tab, VoiceOver. Перевести на
`NSTableView` через `NSViewRepresentable` по образцу сайдбара
(`UI/LeftSidebar/LazyListTable.swift`). Вид и поведение — без потерь,
кроме перечисленного в «Новое поведение».

Префикс путей — `FB Loader/FB Loader/`. Ссылки `file:line` — на `main`
(e6f21d0).

## Границы

- Окно поиска (`UI/Search/*`) не меняется и продолжает рисовать
  `BookRow` с `\.bookTableColumns` из окружения. `BookRow.swift`,
  `CompactCheckbox.swift`, ключ окружения остаются.
- `AppState`, `BooksByContext`, `DateFilterPopover`, `MonthCalendar`,
  `BookDetailView`, сайдбар — без изменений поведения.
  `BooksByContext.Context` получает `Equatable`.
- Не входит: сортировка по клику на заголовок, перетаскивание и ручной
  ресайз колонок. Для будущего ресайза: ширины пересчитываются в
  `frameDidChange` и затрут ручные.

### Действия мышью

- Клик по строке книги — `state.selectedBookLibid = libid`; карточка
  внизу показывает книгу (`BookRow.swift:69`, `MainWindowView.swift:30-46`).
- Клик по галочке переключает `checkedBookLibids`, выбор не меняет
  (`BooksTableView.swift:124-130`).
- Клик по заголовку серии, по пустому месту, по заголовку любой колонки,
  кроме «Даты», ничего не меняет.
- ПКМ по строке книги — меню из одного пункта «Выгрузить отмеченные (N)»,
  N — `checkedBookLibids.count` в момент открытия; неактивен при N = 0;
  выгружает книги с галочками, а не строку под курсором:
  `exportAction.perform()` (`BooksTableView.swift:135-142`;
  fb-loader §6). ПКМ выбор не меняет. На заголовке серии и пустом месте
  меню нет. Обводки строки под ПКМ нет нигде.

### Состояние

- Выбор и галочки живут в `AppState` (`selectedBookLibid`,
  `checkedBookLibids`); таблица их только читает и пишет.
- Сбросы — в `AppState`, таблица их отражает: смена секции, клик по
  другому автору/серии/жанру, язык, фильтр дат гасят выбор и галочки;
  deep-link из карточки гасит галочки, выбор сохраняет
  (`AppState.swift:47-100`; sidebar-tab-state-reset).
- Галочки, снятые выгрузкой (`MainWindowView.swift:111-114`, `:175-176`),
  снимаются в видимых строках.
- Выбранная книга, которой нет в выборке, не подсвечивается; модель не
  трогается.

### Производительность

- Выборка и группировка (`BooksByContext.booksWithTotal` + сборка строк)
  выполняются только при смене контекста, языка, фильтра дат или
  каталога. Не при клике, галочке, ресайзе, проходе `body` главного окна
  (f3ce0ca, 108091b). Крупный жанр (60k книг) — 29 мс
  (books-date-filter «Производительность»).
- `ExportAction` — ссылка, не замыкание (`BooksTableView.swift:3-7`).

## Новое поведение

### Выделение

- Системное выделение, как в сайдбаре: акцентный фон с фокусом, серый
  без; название выбранной книги остаётся `.semibold`. Отменяет §3.3
  ui-polish «без цветной подсветки» (там исправлено).
- На выделенной строке (`backgroundStyle == .emphasized`) тексты
  белые, «.secondary»-колонки — белые полупрозрачные (штатно у
  `NSTableCellView`). Галочка на ней: выкл — прозрачная заливка, белая
  рамка; вкл — белая заливка, галочка `accentColor`. На сером выделении
  без фокуса и на обычной строке — вид из таблицы «Колонки».

### Клавиатура

- Таблица принимает фокус. Tab по кругу: фильтр сайдбара → список
  сайдбара → таблица книг → фильтр сайдбара; Shift-Tab — обратно.
  Остальное — по системной настройке «Навигация с клавиатуры»; своего
  обхода по кнопкам нет.
- Клик по строке книги даёт таблице фокус. Клик по галочке фокус не
  меняет.
- ↑/↓ — предыдущая/следующая книга; заголовки серий перескакиваются.
  На первой книге ↑ и на последней ↓ ничего не делают. Без выбора ↓
  выбирает первую книгу, ↑ — последнюю. Выбранная строка
  прокручивается в видимость; при переходе на первую книгу серии видим
  и заголовок серии. С модификаторами — штатно: ⌥↑/⌥↓ идут в начало и конец списка (первая и последняя книга, не заголовок серии); ⌘↑/⌘↓ шагают на одну строку, как ↑/↓.
- Каждый шаг стрелкой пишет `selectedBookLibid` (карточка следует) — как
  стрелки в сайдбаре (58c5b03).
- Переход по первым буквам названия (type-select): ищет по названиям
  книг, заголовки серий пропускает.
- Пробел ставит/снимает галочку у выделенной строки
  (`tableView.selectedRow`). Без выделения — ничего, без звука.
  Исключение: пробел меньше чем через 1 с после предыдущей буквы
  type-select уходит в поиск.
- Остальные клавиши (Page Up/Down, Home/End) — системные, выбор не
  меняют.
- Заголовок серии не выбирается никаким способом: клик, клавиши, клик с
  модификаторами, type-select.
- Выбор нельзя снять пользователем (клик в пустое место, ⌘-клик).

### Прокрутка при смене выборки

- Смена выборки из сайдбара, языка, фильтра дат — к началу.
- Переход по ссылке из карточки (выбранная книга есть в новой выборке) —
  к этой книге, она выделена, заголовок её серии виден.

### VoiceOver

Таблица — штатная `NSTableView`: строки, колонки, заголовок серии —
групповая строка. Галочка — `checkbox` с меткой «Отметить: <название>».

### Модель строк

```swift
nonisolated enum BookTableRow: Sendable {
    case book(Book, inSeries: Bool)
    case seriesHeader(Series, count: Int)
}

nonisolated struct BookTableRows: Sendable {
    let rows: [BookTableRow]
    func row(ofLibid: Int32) -> Int?          // словарь, строится в init; при дубле — первая
    func isBook(_ row: Int) -> Bool
    func libid(at row: Int) -> Int32?
    /// Заголовок: клавиатура — соседняя книга по направлению от current
    /// (нет такой — current); мышь — current. Пустое предложение — current.
    func resolveSelection(proposed: Int?, current: Int?, byKeyboard: Bool) -> Int?
    enum ScrollTarget: Equatable { case top; case row(Int, header: Int?) }
    func scrollTarget(selectedLibid: Int32?) -> ScrollTarget
    static func build(books: [Book], library: Library) -> BookTableRows
}

nonisolated enum SpaceRoute: Equatable { case toggleCheck, typeSelect }
nonisolated func spaceRoute(lastTypeSelectKey: Date?, now: Date) -> SpaceRoute  // окно 1 с
```

`build` — правило порядка из «Строки»; одинаковые имена серий — по id
серии, одинаковые номера — по порядку выборки.

### Данные и обновление

- `BooksTableContent.body` читает `sidebar`, `languageFilter`,
  `dateFilter` (как сейчас), строит `BookTableRows` и ключ
  `BooksTableKey: Equatable { context, language, dates }` и отдаёт их
  представлению. `selectedBookLibid` и `checkedBookLibids` в `body` не
  читаются.
- `BooksTableRepresentable.updateNSView` читает `selectedBookLibid` и
  `checkedBookLibids` — их смена перезапускает только его (стенд B7).
- `reloadData()` — при смене ключа или `rows.count`. Порядок:
  `reloadData` → `syncSelection` → прокрутка по `scrollTarget`
  (`scrollRowToVisible(header)`, затем `(row)`) →
  `headerView.needsDisplay = true`.
- Смена контекста или `dateFilter` без смены строк тоже ставит
  `headerView.needsDisplay = true` (цвет и доступность «Даты»).
- Смена `checkedBookLibids` или выбора — перерисовка ячеек «Название»
  видимых строк (`reloadData(forRowIndexes:columnIndexes:)`), без
  `reloadData()`.
- Каталог пересобран — `MainWindowView` пересоздаётся через `.loading`,
  представление строится заново.

### Выбор без петель

По образцу `LazyListTable.swift:106-186`:

- `tableViewSelectionDidChange` пишет `selectedBookLibid` строки книги,
  если не поднят `isUpdatingSelection`. При `selectedRow == -1` не пишет.
  Если строка выше — заголовок, `scrollRowToVisible(row - 1)`.
- `syncSelection(of:to:)` и `reloadData` — под `withoutWritingSelection`:
  программная синхронизация в модель не пишет. Выбранной книги нет в
  строках — выделение снимается молча.
- `tableView(_:selectionIndexesForProposedSelection:)` →
  `resolveSelection`; `byKeyboard` — подкласс таблицы поднимает флаг на
  время `super.keyDown` (на время `mouseDown` — нет).
  Стрелки с любыми модификаторами и type-select идут штатным путём
  `NSTableView`; своего `keyDown` для стрелок нет.
- Пробел — `keyDown` подкласса: `spaceRoute` → галочка у
  `selectedRow` через координатор или `super` (type-select). Время
  последней буквы type-select подкласс запоминает в `keyDown` для
  печатных символов без модификаторов, кроме пробела.
- Галочка: своё `NSControl`, `refusesFirstResponder = true`, сама
  обрабатывает `mouseDown`; `validateProposedFirstResponder(_:for:)`
  для неё — `true`, поэтому таблица строку не выделяет. Переключение —
  через координатор, `selectedBookLibid` не пишется.

  - `title` = 16 + 28 + 10 + ширина названия (вложенная строка сдвигает
    содержимое ячейки на 14);
  - `num` = 10 + 50, `size` = 10 + 80, `date` = 10 + 100,
    `genres` = 10 + `genresWidth`;
  - последняя видимая колонка (`genres` или `date`) + 16 справа;
  - сумма ширин видимых колонок = ширина clip view.
- Видимость и ширины — по ширине clip view при её изменении
  (`frameDidChange`): `isHidden` у `size`/`genres`, ширины по
  `columnLayout`. Без `reloadData()` и без прохода SwiftUI `body`.
- Флаги: `style = .plain`, `columnAutoresizingStyle =
  .noColumnAutoresizing`, `allowsColumnResizing = false`,
  `allowsColumnReordering = false`, `allowsColumnSelection = false`,
  `allowsMultipleSelection = false`, `allowsEmptySelection = true`,
  `usesAutomaticRowHeights = false`, `floatsGroupRows = false`,
  `gridStyleMask = []`, `selectionHighlightStyle = .regular`;
  `hasHorizontalScroller = false`, `contentInsets.bottom = 4`.

### Групповые строки

Заголовок серии — `isGroupRow == true` (только групповая строка
получает одну ячейку на все колонки), не липнет, `NSTableRowView` без
системного фона групповой строки. Высота — `heightOfRow`, O(1) по виду
строки.

### Ячейки

`NSTableCellView` с `NSTextField` и своей галочкой; переиспользование по
идентификатору колонки; цвета по `backgroundStyle` (см. «Выделение»).
`NSHostingView` в ячейках нет — дорог на быстрой прокрутке.

### Hover

Отслеживание мыши на таблице: `mouseMoved`/`mouseExited` → строка под
курсором; после прокрутки (`boundsDidChange` clip view) строка
пересчитывается по текущему положению мыши.

### Шапка

- SwiftUI-строка заголовка со счётчиком над `NSScrollView`, код
  `titleRow`/`counter` без изменений: высота 40pt, строка с отступом
  18pt сверху.
- `NSTableHeaderView` высотой 33pt, включая линию 1pt `separatorColor`
  внизу (72–73pt от верха панели); подписи — 2pt от верха шапки
  (42pt от верха панели, как сейчас). Числа — оценка по шрифтам; сверить
  с эталоном ±1pt.
- Своя `NSTableHeaderCell`: подписи по таблице «Шапка над таблицей», без
  вертикальных разделителей; фон шапки — сплошной
  `windowBackgroundColor`. `cornerView = nil`.
- Подкласс шапки обрабатывает `mouseDown` над `date`: приглушение на
  время нажатия, на отпускании над колонкой при наличии контекста —
  открыть или закрыть поповер. Остальные колонки клик игнорируют.
- Поповер: `NSPopover(.transient)` с `NSHostingController(DateFilterPopover)`,
  новым на каждое открытие, `sizingOptions = [.preferredContentSize]`,
  к `headerRect(ofColumn:)` с `preferredEdge`, дающим «под» во
  flipped-шапке. `onApply` → `applyDateFilter` и закрытие.

### Меню

`menu(for:)` подкласса таблицы, без вызова `super`: строка книги под
курсором — меню с пунктом «Выгрузить отмеченные (N)» (`ExportAction`
в координаторе), иначе `nil`. `clickedRow` не выставляется, обводки нет.

## Ручная проверка (Alexey)

До реализации — скриншоты текущей таблицы (широкая и узкая панель,
автор с сериями, активный фильтр дат) как эталон.

- Вид совпадает с эталоном: шапка (линия на уровне линии сайдбара),
  подписи колонок над значениями, отступ книг серии, высоты строк,
  галочки, hover.
- Выделение: акцентное с фокусом, серое без; название жирное; галочка
  на выделенной строке различима во включённом и выключенном состоянии,
  с фокусом и без.
- Сужение панели: «Жанры» исчезают раньше «Размера», «Дата» остаётся,
  подписи не разъезжаются.
- Режим «всегда показывать полосы прокрутки»: подписи над значениями.
- Tab: фильтр → список → таблица → фильтр; Shift-Tab обратно; то же с
  включённой «Навигацией с клавиатуры».
- ↑/↓ (и с ⇧) на крупном жанре: заголовки перескакиваются, края стоят,
  строка в видимости, у первой книги серии виден заголовок, карточка
  следует; зажатая ↓ не роняет карточку.
- Type-select: набор «Война и» находит книгу, галочка не ставится;
  пробел через секунду — галочка.
- Пробел ставит и снимает галочку; клик по галочке выбор и фокус не
  меняет.
- Клик по заголовку серии, пустому месту, заголовкам колонок (кроме
  «Даты») ничего не меняет.
- ПКМ: «Выгрузить отмеченные (N)», неактивен без галочек, выгружаются
  книги с галочками; обводки строки нет; на заголовке серии меню нет.
- Фильтр дат: клик по «Дата» — поповер под заголовком; календарь
  раскрывается целиком; Esc и клик вне закрывают; Enter применяет;
  повторный клик по «Дате» закрывает; «Найти» только после правки; цвет
  заголовка, счётчик «N из M · диапазон», крестик; без контекста
  заголовок неактивен; смена автора снимает фильтр.
- Смена автора/языка/даты гасит выбор и галочки, таблица — в начале;
  deep-link по чипу — книга выделена в новом контексте, видна вместе с
  заголовком серии.
- Hover не залипает после прокрутки колёсиком.
- Крупный жанр (десятки тысяч книг): переключение и прокрутка без
  задержек; ресайз окна не дёргает таблицу.
- Тёмная тема.
- VoiceOver читает строки и галочки; нажатие на «Дату» — если
  поддержано.
