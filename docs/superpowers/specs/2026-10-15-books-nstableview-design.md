# Таблица книг на NSTableView

## Задача

Таблица книг главного окна (`UI/BooksTable/BooksTableView.swift`,
`BookRow.swift`) нарисована вручную: `ScrollView` + `LazyVStack` +
`onTapGesture`. Нет стрелок, фокуса, Tab, VoiceOver. Перевести на
`NSTableView` через `NSViewRepresentable` по образцу сайдбара
(`UI/LeftSidebar/LazyListTable.swift`). Вид и поведение — без потерь,
кроме перечисленного в «Новое поведение».

Префикс путей — `FB Loader/FB Loader/`. Ссылки `file:line` — на `main`
(e6f21d0).

## Границы

- Окно поиска (`UI/Search/*`) не меняется и продолжает рисовать
  `BookRow` с `\.bookTableColumns` из окружения. `BookRow.swift`,
  `CompactCheckbox.swift`, ключ окружения остаются.
- `AppState`, `BooksByContext`, `DateFilterPopover`, `MonthCalendar`,
  `BookDetailView`, сайдбар — без изменений поведения.
  `BooksByContext.Context` получает `Equatable`.
- Не входит: сортировка по клику на заголовок, перетаскивание и ручной
  ресайз колонок. Архитектура им не мешает: колонки — `NSTableColumn` со
  стабильными идентификаторами, ширины считаются по идентификатору, а
  не по индексу, шапка — штатный `NSTableHeaderView`. Ограничение на
  будущее: клик по заголовку «Дата» занят фильтром.

### Действия мышью

- Клик по строке книги — `state.selectedBookLibid = libid`; карточка
  внизу показывает книгу (`BookRow.swift:69`, `MainWindowView.swift:30-46`).
- Клик по галочке переключает `checkedBookLibids`, выбор не меняет
  (`BooksTableView.swift:124-130`).
- Клик по заголовку серии и по пустому месту ничего не меняет.
- ПКМ по строке книги — меню из одного пункта «Выгрузить отмеченные (N)»,
  N — `checkedBookLibids.count` в момент открытия; неактивен при N = 0;
  вызывает `exportAction.perform()` (`BooksTableView.swift:135-142`;
  fb-loader §6). ПКМ выбор не меняет. На заголовке серии и пустом месте
  меню нет.

### Состояние

- Выбор и галочки живут в `AppState` (`selectedBookLibid`,
  `checkedBookLibids`); таблица их только читает и пишет.
- Сбросы — в `AppState`, таблица их отражает: смена секции, клик по
  другому автору/серии/жанру, язык, фильтр дат гасят выбор и галочки;
  deep-link из карточки гасит галочки, выбор сохраняет
  (`AppState.swift:47-100`; sidebar-tab-state-reset).
- После deep-link книга выделена среди книг нового контекста
  (прокрутка к ней — новое, см. «Смена выборки»).
- Галочки, снятые выгрузкой (`MainWindowView.swift:111-114`, `:175-176`),
  снимаются в видимых строках.
- Выбранная книга, которой нет в выборке, не подсвечивается; модель не
  трогается.

### Производительность

- Выборка и группировка (`BooksByContext.booksWithTotal` + сборка строк)
  выполняются только при смене контекста, языка, фильтра дат или
  каталога. Не при клике, галочке, ресайзе, проходе `body` главного окна
  (f3ce0ca, 108091b). Крупный жанр (60k книг) — 29 мс
  (books-date-filter «Производительность»).
- `ExportAction` — ссылка, не замыкание (`BooksTableView.swift:3-7`).

## Новое поведение

### Клавиатура

- Таблица принимает фокус. Tab по кругу: фильтр сайдбара → список
  сайдбара → таблица книг → фильтр сайдбара; Shift-Tab — обратно. При
  включённом «Полном доступе с клавиатуры» в цикл добавляются контролы —
  системное поведение.
- Клик по строке книги даёт таблице фокус.
- ↑/↓ — предыдущая/следующая книга; заголовки серий перескакиваются.
  На первой книге ↑ и на последней ↓ ничего не делают (без перехода по
  кругу). Без выбора ↓ выбирает первую книгу, ↑ — последнюю. Выбранная
  строка прокручивается в видимость; при переходе на первую книгу серии
  в видимость попадает и заголовок серии.
- Каждый шаг стрелкой пишет `selectedBookLibid` (карточка следует) — как
  стрелки в сайдбаре (58c5b03).
- Пробел ставит/снимает галочку у выбранной книги. Без выбора — ничего,
  без звука.
- Остальные клавиши (Page Up/Down, Home/End) — системные, выбор не
  меняют.
- Заголовок серии не выбирается никаким способом: клик, клавиши, клик с
  модификаторами, type-select.
- Выбор нельзя снять пользователем (клик в пустое место, ⌘-клик) — как
  сейчас.

### Смена выборки

При смене контекста, языка, фильтра дат таблица прокручивается к началу;
если выбранная книга есть в новой выборке (deep-link) — к ней. Сейчас
позиция прокрутки при смене не определена (вопрос 3).

### VoiceOver

Таблица — штатная `NSTableView`: строки, колонки, заголовок серии —
групповая строка. Галочка — `checkbox` с меткой «Отметить: <название>».

### Модель строк

```swift
nonisolated enum BookTableRow: Sendable {
    case book(Book, inSeries: Bool)
    case seriesHeader(Series, count: Int)
}

nonisolated struct BookTableRows: Sendable {
    let rows: [BookTableRow]
    func row(ofLibid: Int32) -> Int?          // словарь, строится в init; при дубле — первая
    func isBook(_ row: Int) -> Bool
    func libid(at row: Int) -> Int32?
    enum Direction { case up, down }
    func nextBookRow(from row: Int?, _ direction: Direction) -> Int?   // nil — двигаться некуда
    static func build(books: [Book], library: Library) -> BookTableRows
}
```

`build` — правило порядка из «Строки»; одинаковые имена серий — по id
серии, одинаковые номера — по порядку выборки.

### Данные и обновление

- `BooksTableContent.body` читает `sidebar`, `languageFilter`,
  `dateFilter` (как сейчас), строит `BookTableRows` и ключ
  `BooksTableKey: Equatable { context, language, dates, library:
  ObjectIdentifier }` и отдаёт их представлению. `selectedBookLibid` и
  `checkedBookLibids` в `body` не читаются.
- `BooksTableRepresentable.updateNSView` читает `selectedBookLibid` и
  `checkedBookLibids` — их смена перезапускает только его.
- `reloadData()` — только при смене ключа. Тогда же — прокрутка по
  «Смене выборки».
- Смена `checkedBookLibids`, выбора — перерисовка ячеек «Название»
  видимых строк (`reloadData(forRowIndexes:columnIndexes:)`), без
  `reloadData()`.
- Выгрузка из меню — через `ExportAction`, ссылка в координаторе.

### Выбор без петель

По образцу `LazyListTable.swift:106-186`:

- `tableViewSelectionDidChange` пишет `selectedBookLibid` строки, если
  не поднят `isUpdatingSelection`. Клик и стрелки приходят сюда одинаково.
- `syncSelection(of:to:)` и `reloadData` — под `withoutWritingSelection`:
  программная синхронизация в модель не пишет. Выбранной книги нет в
  строках — выделение снимается молча.
- `tableView(_:selectionIndexesForProposedSelection:)` отбрасывает
  заголовки серий и пустое предложение (оставляет текущее).
- ↑/↓ и пробел перехватывает `keyDown` подкласса `NSTableView`: ↑/↓
  без модификаторов — `nextBookRow` → `selectRowIndexes` +
  `scrollRowToVisible`; пробел — переключение галочки через координатор.
  Прочее — `super`.

### Колонки

- Идентификаторы `title`, `num`, `size`, `date`, `genres`. Галочка — в
  ячейке `title`: только так отступ вложенной строки сдвигает галочку
  и название вместе, а правые колонки стоят на месте.
- Ширины и видимость — из `BookTableColumns` по ширине clip view, при
  её изменении (`frameDidChange`); `isHidden` у `size`/`genres`, ширины
  `title`/`genres`. Без `reloadData()` и без прохода SwiftUI `body`.
- `columnAutoresizingStyle = .noColumnAutoresizing`,
  `allowsColumnResizing = false`, `allowsColumnReordering = false`,
  `intercellSpacing = (10, 0)`, `gridStyleMask = []`, `style = .plain`.
  Отступы 16 по краям — внутри первой и последней видимой ячейки.

### Групповые строки

Заголовок серии — `isGroupRow == true` (только групповая строка
получает одну ячейку на все колонки), `floatsGroupRows = false` (сейчас
заголовки не липнут), `NSTableRowView` без системного фона групповой
строки. Высота строк — `heightOfRow`, O(1) по виду строки.

### Выделение

`selectionHighlightStyle` — единственный переключатель: `.none` + жирное
название выбранной книги (текущий вид) или `.regular` (системное). Выбор
— вопрос 1.

### Ячейки

Нативные: `NSTextField` для текста, своё `NSControl` для галочки с
отрисовкой `CompactCheckbox`. Переиспользование по идентификатору
колонки. `NSHostingView` в ячейках — нет: на каждую видимую ячейку
(~6 × 40) свой SwiftUI-граф и раскладка при каждом переиспользовании,
на быстрой прокрутке 60k строк это заметные пропуски кадров; у
`LazyListTable` то же решение.

### Шапка

- `NSTableHeaderView` со своей `NSTableHeaderCell`: подписи по таблице
  «Шапка над таблицей», без фона и вертикальных разделителей, нижняя
  линия — цвет `separatorColor`.
- Строка заголовка со счётчиком — SwiftUI над `NSScrollView`, код
  `titleRow`/`counter` без изменений; её высота = 72 − высота шапки
  колонок.
- Заголовок «Дата»: ячейка рисует шеврон и цвет состояния; клик
  (`tableView(_:didClick:)` для `date`, если есть контекст) открывает
  `NSPopover(.transient)` с `NSHostingController(DateFilterPopover)`,
  новым на каждое открытие, привязанный к `headerRect(ofColumn:)`.
  `onApply` → `applyDateFilter` и закрытие поповера.

### Меню

`tableView.menu` + `NSMenuDelegate.menuNeedsUpdate`: по `clickedRow`
книги — пункт «Выгрузить отмеченные (N)», иначе меню пустое.

До реализации — скриншоты текущей таблицы (широкая и узкая панель,
автор с сериями, активный фильтр дат) как эталон.

- Вид совпадает с эталоном: шапка (линия на уровне линии сайдбара),
  подписи колонок над значениями, отступ книг серии, высоты строк,
  галочки, hover, жирное название выбранной.
- Сужение панели: «Жанры» исчезают раньше «Размера», «Дата» остаётся,
  подписи не разъезжаются.
- Tab: фильтр → список → таблица → фильтр; Shift-Tab обратно.
- ↑/↓ на крупном жанре: заголовки перескакиваются, края стоят, строка
  в видимости, карточка следует; зажатая ↓ не роняет карточку.
- Пробел ставит и снимает галочку; клик по галочке выбор не меняет.
- Клик по заголовку серии и пустому месту ничего не меняет.
- ПКМ: «Выгрузить отмеченные (N)», неактивен без галочек, выгрузка
  снимает галочки в строках; на заголовке серии меню нет.
- Фильтр дат: клик по «Дата» — поповер под заголовком; «Найти» только
  после правки; цвет заголовка, счётчик «N из M · диапазон», крестик;
  без контекста заголовок неактивен; смена автора снимает фильтр.
- Смена автора/языка/даты гасит выбор и галочки; deep-link по чипу —
  книга выделена в новом контексте и видна.
- Крупный жанр (десятки тысяч книг): переключение и прокрутка без
  задержек; ресайз окна не дёргает таблицу.
- VoiceOver читает строки и галочки.

## Открытые вопросы

1. **Вид выделения.** Сейчас — только жирное название. С клавиатурой
   жирное не показывает, у какого списка фокус, а сайдбар выделяет
   системно. Рекомендация: системное выделение (акцент с фокусом, серое
   без) и жирное название оставить.
2. **Type-select** (переход по первым буквам названия): рекомендация —
   да; пробел остаётся галочкой, поэтому ищется по первому слову.
3. **Прокрутка при смене выборки** — к началу, при deep-link — к
   выбранной книге. Рекомендация: да.
4. **Рамка под ПКМ.** `NSTableView` обводит строку, по которой открыто
   меню; сейчас обводки нет. Рекомендация: оставить системную.
