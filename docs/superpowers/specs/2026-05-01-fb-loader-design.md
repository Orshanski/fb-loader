# FB Loader — Functional Specification

Дата: 2026-05-01

Нативное macOS-приложение для просмотра каталога электронной библиотеки в формате INPX (как у freeLib / MyHomeLib для Flibusta / LibRusEc) и выгрузки выбранных книг из zip-архивов в виде распакованных `.fb2` файлов.

Этот документ описывает **что** приложение делает с точки зрения пользователя. Архитектура, модули, форматы кэша, библиотеки и алгоритмы — в отдельном плане реализации.

### Принцип переноса

Функционал и поведение максимально переносятся из freeLib-mac (исходник: https://github.com/noyatsenko/freeLib-mac, Qt/C++). При реализации алгоритмы из freeLib изучаются точно (парсинг INPX, формат INP, выгрузка из zip, шаблонирование имён, обработка серий и жанров). Допускается локально улучшать алгоритм, если это не меняет наблюдаемое поведение в худшую сторону. **Деградация поведения относительно freeLib недопустима.**

---

## 1. Назначение

У пользователя есть локальная копия библиотеки Flibusta: индексный файл `flibusta_fb2_local.inpx` и ~220 zip-архивов с FB2-файлами внутри (~500 ГБ на внешнем диске).

Приложение позволяет:
- Просматривать каталог по авторам и сериям
- Видеть подробную карточку выбранной книги (включая аннотацию и обложку)
- Отмечать нужные книги галками и выгружать их как обычные `.fb2` файлы в указанную папку

Никакого редактирования, конвертации, отправки куда-либо — только чтение и выгрузка.

---

## 2. Контур

### Делает

1. Открывает один INPX-файл и одну папку с zip-архивами книг (пути выбираются один раз через стандартный системный диалог, дальше помнятся между запусками).
2. Извлекает из INPX каталог: книги, авторы, серии, жанры. Записи, помеченные в INPX как удалённые, в каталог не попадают.
3. При изменении содержимого INPX каталог пересобирается заново при ближайшем запуске приложения. Признак — несовпадение хеша файла с последним обработанным.
4. Показывает каталог с двумя режимами навигации: по авторам и по сериям.
5. Позволяет фильтровать список в левой колонке по подстроке.
6. Позволяет фильтровать книги по языку.
7. Показывает книги выбранного автора или серии, сгруппированными по сериям с раскрывающимися узлами.
8. По выбранной книге показывает подробную карточку с метаданными из FB2-файла, включая обложку.
9. Позволяет отмечать книги галками и выгружать выбранные в указанную папку через контекстное меню.

### Не делает

- Не импортирует пользовательские книги из произвольных файлов
- Не конвертирует форматы (никаких EPUB / MOBI / AZW3 / PDF на выходе)
- Не обращается в интернет за метаданными, обложками, рекомендациями
- Не поддерживает несколько библиотек одновременно (один INPX за раз)
- Не имеет пользовательских тегов, оценок, отметок «прочитано», полок
- Не имеет встроенного просмотрщика книг
- Не отправляет книги на e-mail, Kindle, в облака
- Не запускает OPDS- или HTTP-сервер
- Не предоставляет настроек, кроме указания путей: к INPX, к папке zip-архивов (изменяются через пункт меню приложения «Настройки…»). Папка экспорта запоминается отдельно (см. §6).
- Не предоставляет переключателя `firstAuthor` (которым в freeLib можно настроить, чтобы у автора показывались только книги, где он первый). У FB Loader всегда показываются все книги, где автор упомянут, включая совместные.

## 3. Источники данных

### Вход
- **INPX-файл** (`*.inpx`) — индекс библиотеки. Это zip-архив с набором текстовых индексных файлов внутри. Расположение указывается пользователем; помнится между запусками.
- **Папка с zip-архивами книг** — каталог, в котором лежат архивы, упомянутые в INPX. Указывается пользователем; помнится между запусками.

### Выход
- **Папка экспорта** — каталог, куда сохраняются выгруженные `.fb2`. Не привязана к источникам и выбирается пользователем перед каждой выгрузкой через стандартный системный диалог. Подробное правило — §6.

### Поведение при отсутствии источников
- Если на запуске INPX или папка архивов недоступны (диск не подключён, файл удалён) — приложение показывает диалог с просьбой указать путь заново. До корректного пути основной интерфейс не активен.
- Если при выгрузке нужного архива нет на месте — пользователю показывается ошибка, выгрузка прерывается, уже выгруженные книги остаются.

### Инвалидация кэша каталога
- Каталог пересобирается, когда **содержимое INPX-файла** отличается от того, что было обработано в прошлый раз. Сравнение — по хешу содержимого. Путь к INPX в качестве признака не используется: один и тот же INPX, скопированный в другое место, не вызывает пересборки; новый INPX по тому же пути — вызывает.

## 4. Интерфейс

Главное окно состоит из трёх зон. UI-состояние (размеры зон, активная вкладка, выделение, фильтры) между запусками не сохраняется — приложение всегда стартует в дефолтном виде. Подробности — раздел «Состояние между запусками» ниже.

### Левая колонка
- Сегментированный переключатель сверху: **Авторы / Серии**.
- Поле «Фильтр» — подстрочный поиск в текущем списке (фильтрует по мере набора).
- Список:
  - в режиме **Авторы**: имена авторов в формате «Фамилия Имя Отчество» с числом книг в скобках; сортировка по фамилии. Книги без указанного автора собираются под отдельной карточкой «(Без автора)».
  - в режиме **Серии**: названия серий с числом книг в скобках; сортировка по названию.
- Число в скобках = количество всех книг в каталоге, относящихся к этой карточке. Для авторов — все книги, где автор упомянут (включая совместные); это совпадает с правилом таблицы справа. Для серий — все книги серии. Псевдо-автор «(Без автора)» — все книги без указанного автора.

### Правая верхняя зона
- Над таблицей — фильтр **«Язык книг»** (выпадающий список языков, встретившихся в каталоге; по умолчанию `RU`). Книги, у которых язык в INPX пустой или нечитаемый, попадают в отдельную категорию **«Не указан»** в этом же фильтре.
- Таблица книг выбранного слева автора или серии, сгруппированных по сериям:
  - Когда слева выбран **автор** — показываются все книги, в которых он указан как один из авторов (включая совместные книги с соавторами).
  - Когда слева выбрана **серия** — показываются все книги, относящиеся к этой серии.
  - Когда слева выбран псевдо-автор **«(Без автора)»** — показываются все книги без указанного автора.
  - Книги вне серий — плоско сверху.
  - Серия — раскрывающийся узел (`disclosure`), внутри книги в порядке номера в серии.
- Колонки таблицы: **галка**, **Название**, **№ в серии**, **Размер**, **Дата добавления**¹, **Жанр** (все жанры книги через запятую; при недостатке ширины колонки — обрезание с многоточием).
- Контекстное меню (ПКМ) на строке: пункт **«Выгрузить отмеченные»**. Пункт активен только если в таблице есть хотя бы одна галка. ПКМ при отсутствии галок ничего не делает (пункт неактивен или скрыт).

¹ «Дата добавления» — это дата добавления книги в библиотеку Flibusta (берётся из INPX), не дата на пользовательском компьютере.

### Правая нижняя зона
Карточка выбранной в таблице книги:
- Название (крупно)
- Авторы
- Жанры
- Серия и номер в серии
- Дата написания
- Переводчики
- Аннотация
- Обложка (справа)

Авторы и серии в карточке отображаются как кликабельные ссылки. Клик по ссылке переводит фокус в левую колонку: переключает вкладку (Авторы / Серии) и выделяет соответствующий элемент. Таблица справа перерисовывается под новый контекст. Жанры показываются как обычный текст (вкладки «Жанры» в левой колонке нет).

### Состояние между запусками
Между запусками сохраняются **только три пути**:
- Путь к INPX-файлу
- Путь к папке zip-архивов
- Путь к последней выбранной папке экспорта (используется как предзаполнение в диалоге выбора, см. §6)

Всё остальное — размеры зон главного окна, активная вкладка левой колонки, выделение в списках, выделение книги в таблице, значение фильтра «Язык книг» — **не сохраняется**. При каждом запуске UI стартует в дефолтном состоянии: вкладка «Авторы», ничего не выделено, фильтр `RU`.

Пути сохраняются как обычные `URL` (без security-scoped bookmarks), поскольку App Sandbox выключен.

## 5. Поиск и фильтрация

### Подстрочный фильтр в левой колонке
- Применяется к текущему списку (авторы или серии).
- Регистронезависимый, по подстроке.
- Реагирует мгновенно на ввод символов.

### Фильтр по языку
- Применяется к таблице справа.
- Список значений строится из реально встретившихся в каталоге языков (`ru`, `en`, …).
- По умолчанию выбран `ru`.
- Книги, у которых поле языка в INPX пустое или нечитаемое, попадают в отдельную категорию **«Не указан»** в этом же выпадающем списке.

### Глобальный поиск книг
В этой версии не реализуется. Запланирован отдельной задачей — нечёткий поиск по названию книги.

## 6. Экспорт

### Запуск
- Чтобы что-то выгрузить, надо отметить галки в нужных строках таблицы.
- Контекстное меню (ПКМ) на любой строке: пункт **«Выгрузить отмеченные»**. Пункт активен только если в таблице есть хотя бы одна галка.
- Без галок выгрузка не запускается — никаких неявных действий вроде «выгрузить книгу под курсором» нет.

### Папка экспорта
- **Перед каждой выгрузкой** открывается стандартный системный диалог выбора папки.
- В диалоге предзаполнена та папка, которую пользователь выбрал в прошлый раз. При первом запуске или если запомнённый путь стал недоступен — предзаполнено `~/Downloads`.
- Если пользователь подтвердил выбор — путь сохраняется как «последний» для следующего раза, выгрузка начинается.
- Если нажал Cancel — выгрузка не выполняется, запомнённый путь не меняется.

### Структура и имена файлов
- Структура: **`<Корневая папка>/<Автор>/<Название>.fb2`**, где:
  - `<Автор>` — имя автора, выбранного в левой колонке. Берётся именно выбранный автор, а не первый автор книги. Например, если выбран соавтор и у его книги есть другой первый автор — папкой всё равно становится выбранный.
  - Если экспорт инициирован из вкладки «Серии» (автор не выбран) — папкой становится первый (основной) автор книги.
  - Если у книги нет указанного автора — папкой становится «(Без автора)».
  - `<Название>` — название книги из INPX.
- Запрещённые в файловых именах символы заменяются на `_`. Длинные имена обрезаются до системного лимита.

### Поведение при коллизиях
- Если файл с таким именем уже существует в целевой папке — он перезаписывается без вопросов и предупреждений.

### Прогресс и отмена
- Во время выгрузки отображается прогресс: количество обработанных и общее количество, имя текущей книги.
- Кнопка «Отмена» прерывает процесс. Уже сохранённые на диск файлы не удаляются.

### Что выгружается
- Распакованный `.fb2` — содержимое книги внутри её zip-архива, без дополнительной упаковки и без конвертации.

## 7. Поведение при ошибках

| Ситуация | Реакция |
|---|---|
| INPX не найден / повреждён при запуске | Диалог «Укажите INPX заново», основной интерфейс заблокирован до выбора |
| Папка zip-архивов недоступна при запуске | Диалог «Укажите папку с архивами заново», аналогично |
| Конкретный zip-архив отсутствует / повреждён при выгрузке | Сообщение об ошибке для этой книги, выгрузка остальных продолжается |
| Книга, помеченная в INPX как удалённая | В каталог не попадает, в UI не видна |
| Книга без указанного автора в INPX | Попадает в каталог под псевдо-автором «(Без автора)» |
| Незнакомый код жанра в INPX | Жанр показывается под именем, равным самому коду, в разделе «Прочее». Название вместо кода сопоставляется со словарём |
| Книга с пустым/нечитаемым языком в INPX | Попадает в каталог, в фильтре языка — категория «Не указан» |
| Битая запись INPX | Пропускается, парсинг продолжается |

## 8. Платформа и распространение

- macOS 26 Tahoe и новее
- Native Swift / SwiftUI
- App Sandbox выключен (не для Mac App Store)
- Hardened Runtime включён, бинарь подписан Developer ID, проходит нотаризацию Apple
- Запуск — двойным кликом по `.app` в `/Applications`
- Распространение — личное / семейное; публикация в Mac App Store не планируется
