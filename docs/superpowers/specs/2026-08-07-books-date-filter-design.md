# Фильтр по дате в таблице книг

## Задача

Показывать в таблице книг только те, что добавлены в библиотеку в
заданном диапазоне дат.

## Дата книги

В INPX дата записана строкой `YYYY-MM-DD` — календарный день, без
времени.

Раньше она хранилась числом дней от 2000-01-01 (`dateAddedDays: Int32`)
ради двух мегабайт памяти, а наружу отдавалась вычисляемым `Date` через
`Calendar.date(byAdding:)`. Экономия не стоила того, что дата в модели
перестала быть датой: каждое обращение к ней — календарная арифметика,
а любое сравнение требовало перевода туда-обратно.

Теперь `Book.dateAdded: Date?` — хранимое поле. `nil`, если даты в
записи не было. При импорте дата строится из года, месяца и числа, то
есть на полночь своего дня; границы фильтра приводятся к полуночи тем
же способом. Сравниваются две полуночи, переводов нет.

Формат бинарного кэша поднят с 2 до 3: поле стало восьмибайтовым
(`timeIntervalSinceReferenceDate`, `NaN` — даты нет). Старый кэш
отвергается по версии и переразбирается при первом запуске.

## Границы задачи

Не меняются: левый сайдбар (`UI/LeftSidebar/*`) и окно поиска
(`Search/SearchCoordinator.swift`, `UI/Search/*`).

## UI

Клик по заголовку колонки «ДАТА» открывает поповер:

```
┌──────────────────────────────┐
│  с   [ 01.01.2000      📅 ]  │
│  по  [ 07.08.2026      📅 ]  │
│  ──────────────────────────  │
│      ‹  Февраль ⌄ 2026 ⌄  ›  │
│      пн вт ср чт пт сб вс    │
│           …сетка месяца…     │
│           Сегодня            │
│  ──────────────────────────  │
│  Сбросить            Найти   │
└──────────────────────────────┘
```

**Фильтр применяется только по кнопке «Найти».** Правка полей до
нажатия не делает ничего: иначе набор года с клавиатуры срабатывал бы
на каждой цифре, пересчитывая таблицу и снимая галочки.

«Сбросить» снимает фильтр. Обе кнопки закрывают поповер.

Клик по полю раскрывает под ним сетку месяца; клик по числу ставит дату
в поле и сворачивает сетку. Поля при повторном открытии помнят, что в
них набрали, — даже если поповер закрыли по Esc.

По умолчанию «с» = 01.01.2000, «по» = сегодня. «Найти» с нетронутыми
полями ничего не отсекает.

### Заголовок колонки

`Text` → `Button` с шевроном справа, вся группа в тех же
`BookRow.dateWidth` (100pt). Правый край колонки держит шеврон, подпись
стоит левее — как индикатор сортировки в Finder. При активном фильтре
заголовок красится `.tint`.

Кнопка выключена, пока в сайдбаре не выбран автор, серия или жанр.

### Счётчик

`breadcrumbRow` → `titleRow`, `breadcrumbLabel` → `titleLabel`
(навигационной цепочки там нет, имя досталось по инерции).

| состояние | справа в строке |
|---|---|
| фильтра нет | `264 книги` — со склонением, как было |
| фильтр активен | `12 из 264 · 01.01.2024 — 07.08.2026` + кнопка сброса |

«N из M» — голыми числами, без склонения, и показывается всегда, в том
числе «0 из 264»: иначе у пустой таблицы исчезает единственное
объяснение, почему она пуста.

Кнопка сброса — отдельная `Button` с `xmark.circle.fill`, не глиф
внутри текста: нужна внятная зона клика.

### Шапка внутри прокрутки

Шапка таблицы переехала внутрь `ScrollView` закреплённой секцией
(`pinnedViews: [.sectionHeaders]`). Снаружи она была шире строк ровно на
ширину полосы прокрутки, и подписи колонок стояли правее своих значений.

Побочно: содержимое `ScrollView` macOS пускает под панель окна, поэтому
`MainWindowView` получает `.toolbarBackground(.visible, for:
.windowToolbar)` — иначе строки просвечивают в полосе заголовка.

## Модель

```swift
nonisolated struct DateRangeFilter: Equatable, Sendable {
    let from: Date
    let to: Date

    func contains(_ book: Book) -> Bool
    var label: String          // «01.03.2013 — 30.06.2015»
}
```

Обе границы всегда заданы — поповер не даёт их не задать. Отсутствие
фильтра — `nil` у `AppState.dateFilter`. `from > to` даёт пустой список.

`DateFormat.dayMonthYear` — единственный `DateFormatter` приложения:
он строится на каждую видимую строку таблицы, а `DateFormatter` дорог.

## Фильтрация

```swift
static func booksWithTotal(for ctx: Context,
                           language: String,
                           dates: DateRangeFilter?,
                           in lib: Library) -> (books: [Book], total: Int)
```

Числитель и знаменатель считаются **одним проходом по одному
множеству** — отдельный предпосчитанный счётчик дал бы расхождение на
книгах, которые фильтр отбрасывает по причинам, о которых счётчик не
знает.

`books(for:language:dates:in:)` остаётся обёрткой с `dates` по
умолчанию `nil` — вызовы из окна поиска не тронуты.

Фильтр применяется до группировки по сериям: серия без уцелевших книг
исчезает вместе с заголовком, счётчик в её заголовке показывает
оставшиеся.

## Состояние

```swift
private(set) var dateFilter: DateRangeFilter? = nil
func applyDateFilter(_ next: DateRangeFilter?)
```

`applyDateFilter` — путь из поповера и из кнопки сброса в шапке. No-op
при равном значении, иначе гасит `selectedBookLibid` и
`checkedBookLibids`. Один раз, по нажатию кнопки.

### Сброс при смене контекста

`dateFilter` обнуляется там же, где `checkedBookLibids`, — во всех трёх
сценариях [майской спеки](2026-05-26-sidebar-tab-state-reset-design.md),
и в `reset()`.

**Прямым присваиванием, не через `applyDateFilter`:** иначе deep-link из
карточки книги погасил бы `selectedBookLibid`, который по майской спеке
обязан сохраняться.

No-op-гарды сохраняются: повторный клик по уже выбранному автору фильтр
не трогает. `languageFilter` фильтр дат не трогает.

### Инвариант: сайдбар не пересчитывается

1. `dateFilter` не входит в `filterKey`
   (`UI/LeftSidebar/FilteredSidebarList.swift`) — иначе `.task(id:)`
   погонит скан по всем авторам на каждое «Найти».
2. Ни один view в `UI/LeftSidebar/` не читает `dateFilter`.

## `MonthCalendar`

Своя сетка месяца, `UI/Components/MonthCalendar.swift`. Системный
`DatePicker(.graphical)` выглядит как контрол из девяностых и не
стилизуется.

- Шапка: `‹ Февраль ⌄ 2026 ⌄ ›`. Стрелки шагают на месяц, месяц и год —
  отдельные меню. Год меню, а не стрелками: из 2026 в 2009 — двести
  кликов.
- Понедельник первым, подписи дней двухбуквенные: однобуквенные в
  русской локали неразличимы («П» — и понедельник, и пятница), и они же
  давали дублирующиеся ID в `ForEach`.
- Выбранный день — залитый кружок, сегодняшний — кольцо. Дни соседних
  месяцев не рисуются.
- Кнопка «Сегодня» под сеткой.

## Производительность

Замер на каталоге полного размера (581k книг), Apple Silicon, `-O`:
крупный жанр (60k книг, 8k серий) без фильтра — 29 мс, с широким
диапазоном — 14 мс, с узким — 3 мс. Меряется весь конвейер: фильтрация,
разделение на одиночные и серийные книги, сортировка.

Фильтр не может ничего замедлить: чем уже диапазон, тем меньше книг
доживает до группировки и сортировки, а они и есть основная работа.

## Ручное UI-тестирование

- Клик по «ДАТА» открывает поповер; в полях 01.01.2000 и сегодня.
- Отметить книги, открыть поповер, набрать год — таблица не дёргается,
  галочки на месте, пока не нажата «Найти».
- После «Найти»: заголовок акцентный, «12 из 264 · диапазон», галочки и
  превью сброшены.
- Повторное открытие показывает выбранные даты.
- Крестик в шапке и «Сбросить» возвращают «264 книги».
- Смена автора снимает фильтр, повторный клик по тому же — нет.
- Deep-link по чипу автора снимает фильтр, превью книги сохраняет.
- Крупный жанр с узким диапазоном: пустые серии исчезают, счётчики в
  заголовках серий уменьшаются.
- Сайдбар при применении фильтра не мигает и не теряет прокрутку.
- В окне поиска фильтра дат нет.
